# 第一次回复
``` TEXT
1. 数据速率修改为1MHz * 64 bit
2. 只要求正常连接期间无丢失,采集时有命令控制的,采集时间至少72小时
3. 启动数据采集命令后，板端持续发送数据帧，期间可接收停止/状态命令,允许在 Data 内加入会话号、序号、样本数和校验值
4. SD卡作为一个配置选项,可以只上传 只存储 存储且上传.SD卡容量为64GB存满后不在进行存储,上传SD卡满错误
5. PS使用裸机程序
6. 是 领航者ZYNQ7020 板卡,PSDDR 1GB芯片型号一致
7. 需要 连接配置、开始/停止、SD/网络模式选择、接收速率、连续性校验、文件保存和错误日志 需要实时波形显示
```
