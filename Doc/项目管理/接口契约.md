# PL 与 PS 接口契约

版本 v1.0，2026/09/26。修改必须由协调者同步通知所有实现者。

- PL AXI 时钟 100 MHz；固定每 100 周期产生一个 64 bit 无符号递增样本，从 0 开始。不能将反压当成降采样手段；超过缓冲能力锁存溢出并停止，交由 PS 报错。
- 每块 4096 样本，32768 字节；AXI-Stream TDATA=64、TKEEP=8'hFF、TLAST 标记块最后一拍。VALID 为高且 READY 为低时数据和边带保持稳定。
- 两块各 4096×64 的 BRAM；仅完整块可读，读完最后一次握手才释放；停止在当前采样块边界生效，最多延迟 4.096 ms。
- AXI DMA S2MM SG 模式，64 bit 数据，长度至少支持 32768。PS 通过 HP0 访问 DDR，CPU 通过 GP0 控制 DMA/采集寄存器。
- 采集控制 AXI-Lite 地址 0x43C00000；DMA 地址 0x40400000。采集模块实例名 daq_core_0，DMA axi_dma_0，PS processing_system7_0。

|偏移|名称|定义|
|---|---|---|
|0x00|CONTROL|RW bit0 RUN 请求，bit1 CLEAR 单次脉冲；CLEAR 只在停止并排空后允许，清计数及溢出|
|0x04|STATUS|RO bit0 采样运行，bit1 尚有待输出数据，bit2 溢出锁存|
|0x08|SAMPLES_LO|RO 已生成样本计数低 32 bit|
|0x0C|SAMPLES_HI|RO 已生成样本计数高 32 bit；软件高低高重读取得一致快照|
|0x10|BLOCK_SAMPLES|RO 4096|
|0x14|SAMPLE_HZ|RO 1000000|
|0x18|VERSION|RO 0x00010000|

- 启动顺序：校验空闲 → CLEAR → 建立 DMA 接收队列/输出资源 → RUN=1。停止顺序：RUN=0 → 等待采样和 BRAM 排空 → 回收并发送/保存 DMA 完整块 → 回复停止完成。
- PS 所有权：DMA 写入块在回收后才能读取；网络未复制完/SD 未完成前不可还给 DMA。不能循环覆盖消费者仍持有的块。
- 使用描述符和数据缓存 flush/invalidate；DDR 缓冲不与 ELF 堆、栈、BSP 堆重叠。具体内存分区由 PS 实现记录。
- PS 处理接口仅透传，保留将来处理入口，不修改样本与序号。
