# DAQ 需求与验收

版本 v1.0，2026/09/26。依据本任务用户确认。

## 已确认需求

1. 领航者 ZYNQ7020，xc7z020clg400-2，DDR 1 GB；Xilinx 2022.1。
2. 每秒 1,000,000 个 64 bit 样本，原始吞吐 8,000,000 Byte/s。PL 内部可以使用 100 MHz 时钟、100 周期采样使能，数据发生器必须按真实采样节拍产生样本。
3. PL 双 BRAM 块缓冲，AXI DMA 写 PS DDR；PS 裸机处理占位模块保持数据不变。
4. 正常网络连接及足够接收能力下，连续上传至少 72 小时，无缺失、乱序、重复或校验错误。断网无限补传不在范围内；故障必须报告，不能静默继续假装完整。
5. 只上传、只存储、同时存储上传。64 GB SD 满后不覆盖、不继续写。只存储时结束采集；同时输出时保留网络上传并上报 SD 满。
6. PC 连接配置、开始/停止、模式选择、接收速率、连续性校验、可选分卷文件保存、错误日志、实时波形。波形允许显示抽取，原始接收/校验/保存不得抽取。
7. 保持网络配置、外层协议框架、小端字节序。允许启动后持续推送并同时处理停止/状态命令，允许数据区元数据。
8. 每个小阶段 commit & push 至 https://github.com/HQY-DEBUG/DAQ；PL/PS 修改写 ReadMe，工具修改写版本历史。

## 容量与验收边界

- 72 小时共 259,200,000,000 样本、2,073,600,000,000 原始字节，必须使用 64 bit 计数器。
- 标称 64 GB SD 理论原始容量约 8,000 秒，文件系统、元数据及保留空间使可用时长更短；SD 模式不承诺存满 72 小时。
- 正常连接不等于无限吞吐：上板必须验证 SD 写入停顿、PC 磁盘停顿、TCP 拥塞下的最大队列占用和恢复能力。
- 队列满、PL 溢出、DMA 故障、SD 故障、PC 磁盘满均必须可见。不得在无证据情况下承诺硬件吞吐或 72 小时稳定性。

## 分阶段验收

1. 工程基线：规则、契约、目录、Git、版本锁定。
2. PL：固定采样节拍、64 bit 递增数据、双 BRAM 所有权、反压稳定、块边界停止、溢出锁存；仿真、BD 验证、综合实现和时序。
3. PS：SG DMA 描述符和缓存一致性、块所有权、lwIP 流式收发、CRC、SD 分卷和卡满行为；交叉编译及主机可运行逻辑测试。
4. PC：TCP 拆粘包、协议拒绝、会话/序号/CRC 校验、独立接收及显示路径、分卷保存；Qt 构建和模拟服务器集成测试。
5. 联调：生成 bit/XSA/ELF/BOOT.BIN，连接板卡后验证启动、三种模式、反复开始停止、卡满、故障报告。
6. 72 小时测试：留存会话、首尾样本、块数、错误计数、速率、最大队列、日志及文件校验结果。
