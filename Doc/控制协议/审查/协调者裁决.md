# 协议 v1.1 协调审核记录

日期：2026/09/26。当前结论：语义修订已写入，PL 独立对话 v1.1 复核无阻断冲突；Word 模板一致性与最终复核未完成。尚未冻结，不能启动 PL 实施阶段。

## 审查输入与处理

|问题|统一裁决|依据位置|
|---|---|---|
|排空中 RUN 可能延后重启|START 仅 IDLE；硬件拒绝待输出/溢出时的新 RUN，运行中的 RUN=1 幂等|网络“会话与状态转换”；PL/PS“受理与故障语义”|
|PL pending 与系统停止混淆|STOP 等待 PL、DMA、消费者、TCP 完整帧入队和正常 SD 同步关闭，释放旧 DMA 所有权|网络“停止与异常完成条件”|
|故障通知与尾帧顺序|先 DRAINING 通知，可发已验证完整前缀，最后 FAULT 通知；有待答 STOP 才发失败应答|网络“停止与异常完成条件”|
|SD 满与正常结束混淆|只存储故障停止；双输出继续上传；双输出随后停止可为 IDLE 加 SD 错误|网络“SD 存储行为”|
|SD 写入与持久化计数|stored_blocks 只统计最近成功同步涵盖的完整帧；短写/同步失败不能虚增|网络“状态与应答”“SD 存储行为”|
|STOP 与 STATUS 并行关联|按 Type 各一个待答标记；帧级串行发送；同 Type 并发禁止，非法重复 STOP 回 BUSY|网络“固定外框与连接”|
|会话 RESET 与重连|RESET 清会话快照但不回退 ID 分配器；重连不续传，先清理旧资源|网络“会话与状态转换”|
|PL 溢出次数缺寄存器|由 PS 对本会话硬件锁存首次置位计一次，本版值为 0/1|状态 overflow_count 定义|
|无丢失计数证明|正常终态用 produced_samples 与各启用路径块数建立等式；PC独立 CRC/序号复核|网络“状态与应答”|
|文件保存与接收状态不同|PC 保存失败显式停保存但继续接收校验，不把上传成功等同持久化成功|网络“文件与显示”|
|Word 新旧格式混搭|以 Git 基线原始 Word 包为模板，保留页边距、样式和固定表，不再用空文档重建|用户格式反馈；Luna 对话格式修正任务|

## 已执行的只读校验

- 固定地址 192.168.1.10:7、掩码 255.255.255.0、网关 192.168.1.1、帧头 0xA5A5A5A5、帧尾 0xB5B5B5B5 均在协议中保留。
- 状态字段偏移连续覆盖 0..63，共 64 字节；数据元信息 40 字节，样本 32768 字节，DataSize=32808，外框后总长 32824。
- 使用 Python 标准库 struct/zlib 独立计算：4096 个递增 uint64 样本（0..4095）的小端原始字节 CRC-32 为 0x30F674A6。
- 只上传 START 请求共 32 字节，小端黄金向量如下，可用于后续 PS/PC 跨语言测试：

```text
A5 A5 A5 A5 FF 00 01 C0 10 00 00 00 01 00 00 00
40 42 0F 00 00 10 00 00 00 00 00 00 B5 B5 B5 B5
```

- 72 小时为 259200000000 样本、2073600000000 原始字节，uint32 计数不足，协议使用 uint64。

## 冻结门槛

1. PL 接口对 v1.1 复核无未解决阻断项。
2. Word 与 Markdown 字段、命令、终态和异常行为一致；固定两表逐单元格一致。
3. Word 全部页面渲染检查完成，格式与原始模板一致，表格和分页可读。
4. 协调者检查差异，更新 ReadMe/进度，独立提交协议阶段并推送。满足后才能明确启动 PL 对话，PS/PC 继续等待。

PL 复核补充建议已采纳：非法 RUN=1 返回 SLVERR、不改变状态；细化 AXI-Lite 地址检查、字节使能和错误读值，作为 PL 阶段仿真要求。

## Word 候选版复查

已视觉检查 Luna 生成的首轮模板候选全部 8 页（artifacts/protocol-reference/candidate-render）。原始页边距、编号标题、字体与紫色表格体系已恢复，但发现以下必须修正项，已回交同一 Luna 对话处理：

- 各命令应展示完整外框字段表，不能只列 Data 载荷；与原始系统命令表的表达方式保持一致。
- 数据/状态明细表不能将字节偏移写在“参数标识”列；标识必须是实际字段名，偏移单独说明。
- DRAINING 状态表必须同时覆盖首次 STOP 登记及重复 STOP 返回 BUSY。
- result 错误枚举拆为独立表以避免单元格过高；短验收条目避免跨页拆句。

这轮候选未批准成为正式文档。修正后必须再次核对完整字段、所有页面和固定两表，不能沿用本轮页图冒充最终验证。
