## 契约与固定表

- Word 中网络表的 IP `192.168.1.10`、掩码 `255.255.255.0`、网关 `192.168.1.1`、TCP 端口 `7` 与原参考件逐单元格相同。
- 外层表的六列、Hard/Tail 常量、字段行和单元格值均与原参考件一致。参考表和正式稿候选表的规范化 XML 相等；未改网络参数或外框。
- 请求帧表按原六列表逐项列 Hard、Type、DataSize、Data、Tail。RESET/STOP/STATUS 空载荷表只列 Hard、Type、DataSize、Tail 四行，序号为 1–4；START DataSize=16，状态应答=64，数据推送=32808，异常通知=64。命令应答另列沿用请求 Type 的完整外框，异常 Type 为 `0xC00400FF`。
- 数据区明细使用中文数据名称及独立英文标识列；元数据/状态字段偏移、长度、类型和值均与 v1.1 对齐。状态应答为 64 字节；错误码 0–9 单列成表，state 与 sd_state 枚举值完整。未知 Type 的 BAD_REQUEST 处理在外框行为段说明。
- 内容覆盖逐字节拆粘包、非法帧断连/BAD_REQUEST、会话 ID、状态转换、STOP/STATUS 并行应答、DRAINING 首次 STOP 登记及重复 STOP 返回 BUSY、故障清理、SD 满策略、PC 保存关闭后仍接收校验、`.daq` 外框/分卷/独占新建规则、波形与最低验收场景。
