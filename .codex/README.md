## 协作约定

|角色|模型|写入范围与职责|
|---|---|---|
|协调与复查|GPT-6 Astra|共享规则、协议、ReadMe、Git 提交推送、跨模块审核与集成|
|PL 实现|GPT-6 Sol|PL/ 内源码、Tcl、约束、仿真、构建与验证记录|
|PS 实现|GPT-6 Sol|vitis/ 内裸机程序、构建、测试与验证记录|
|PC 实现|GPT-6 Sol|PC/ 内 Qt 上位机、模拟服务器、构建、测试与验证记录|
|简单整理|GPT-6 Luna|按协调者指定的独立范围整理；不得未经审核改变接口|

模型分工由派发任务时明确指定，本 Markdown 不会自动切换模型。代理不独立修改共享协议或提交 Git；遇到契约冲突先报告协调者。

## 保存与提交

每完成一个可验证里程碑，先将命令、结果、遗留问题写入对应模块的“验证记录.md”，再由协调者汇总进度、更新版本并 commit & push。遇到暂停或重启，以已保存文件和实际 Git 状态为准，不能将聊天中的计划当作已完成工作。
