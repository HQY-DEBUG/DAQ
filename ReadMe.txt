# DAQ 数据采集系统

硬件：领航者 ZYNQ7020（xc7z020clg400-2），PS DDR 1 GB。
工具：Vivado/Vitis 2022.1；PC 使用 Visual Studio + Qt。
采样：1 MHz × 64 bit，8 MB/s；正常连接期间目标连续采集至少 72 小时。

设计与恢复入口：AGENTS.md、Doc/项目管理/需求与验收.md、接口契约.md、进度与交接.md。
协议入口：Doc/控制协议/协议实现约定.md，保留原网络配置和外层帧结构。
